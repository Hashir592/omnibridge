Routes (packages/contract/src/routes/catalogue.ts, tab stock-catalogue, workspace-shared):
1. Master SKUs:
   - listMasterSkus: numbered pages, with q, active and bundles filters.
   - getMasterSku: the VAT-type and COGS histories plus listings.
   - createMasterSku: a bundle sends bundle {component_id, pack_size >= 2} and no vat_type or COGS. There is no field for a second component (CAT-3, AT-5).
   - updateMasterSku: the SKU code and a bundle's make-up are read-only. A VAT change sends vat {vat_type, effective_from}; a bundle answers 409.
2. listManufacturers: the dropdown (CAT-1).
3. VAT rates: listVatRates. createVatRate is admin only (settings tab).
4. COGS:
   - listCogs.
   - setCogs: the same date replaces; a bundle answers 409.
   - importCogs {csv, dry_run}: columns sku, cogs (pounds, 12.34), effective_from (DD/MM/YYYY or YYYY-MM-DD).
5. Listings:
   - listListings: mapped=false is the Unmapped queue.
   - mapListing: 409 when already mapped to another SKU.
   - unmapListing.
   - importMappings {csv, dry_run}: columns listing_id, sku; an empty sku unmaps.
   - exportMappings: a CSV file.
Both imports return a CsvImportReport {rows, valid, applied, errors[{line, code, column}]}. They are all or nothing: applied is false on a dry run or when any row fails.
Money is integer pence and rates are basis points (2000 = 20%). Show dates as DD/MM/YYYY.
