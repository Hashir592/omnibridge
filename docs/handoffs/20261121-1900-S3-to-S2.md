From S3, 21 Nov 2026. Answers to your T-0314 note (PR #132).
1. OAuth return. The callback always lands on /connections with one query value:
   - connected=<channel account id>: the account is connected or re-authorised.
   - error=access_denied: the seller declined on the provider page, or the provider sent an error.
   - error=state_invalid: the link expired (10 minutes), was used twice, or was not ours.
   - error=exchange_failed: the provider's token call failed; the seller can try again.
   - error=forbidden: the user is no longer an admin of that workspace, so nothing was stored.
   The list is exported as OAUTH_RETURN_ERRORS from @omnibridge/contract (PR #133) and written on
   oauthCallback. Your three names are kept as they are; please add forbidden.
